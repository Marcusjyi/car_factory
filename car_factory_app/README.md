# CARFACTORY App (Flutter)

중고 자동차 부품 C2C 마켓플레이스 모바일 앱.

백엔드·스키마는 `car_factory`(스토어/Functions)와 동일합니다.

```bash
cd car_factory_app
flutter pub get
flutter run
```

| 항목 | 값 |
|------|-----|
| Firebase | `car-factory-40a14` |
| Firestore | named `default` |
| Functions | `asia-northeast3` |
| package | `com.carfactory.car_factory_app` |

관련 폴더: `car_factory_admin/`(어드민), `car_factory/`(스토어·Functions), `카팩토리 개발문서/`
