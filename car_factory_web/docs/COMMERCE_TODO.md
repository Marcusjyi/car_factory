## 현재 방향 (PG 보류)

당근 초창기처럼 **PG 없이 직거래**를 먼저 씁니다.

| 결제 방법 | 설명 |
|-----------|------|
| 만나서 결제 | 약속 장소에서 확인 후 현금·현장 송금 |
| 계좌이체 | 판매자 계좌로 입금 |

### 상태 플로우

```
selling(판매중)
   │ 채팅으로 합의 → 판매자 「예약중으로 표시」
   ▼
reserved(예약중)  ← orders.status = reserved
   │ 판매자 「판매완료」 / 판매자 「예약 취소」
   ├──────────────────┐
   ▼                  ▼
sold(판매완료)     selling(다시 판매중)
orders.completed   orders.cancelled
```

### 권한

| 액션 | 판매자 | 구매자 |
|------|--------|--------|
| 예약중으로 표시 | O | X |
| 예약 취소 | O | X (채팅으로 요청) |
| 판매완료 | O | X |
