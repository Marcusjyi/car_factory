# 00. AI·코딩 가드레일 (필수)

코드 작성 전·중·후에 반드시 지킨다. 위반 시 버그·보안·배포 사고로 이어진다.

최종 갱신: 2026-08-04

---

## 작업 시작 전

1. `카팩토리 개발문서/README.md` 목차를 확인한다.
2. 작업 영역에 해당하는 문서를 읽는다 (데이터/커머스/앱별).
3. 관련 실제 코드·`firestore.rules`·`functions/src`를 대조한다.
4. 초기 스펙(`CARFACTORY_CURSOR_…SPEC…`)만 보고 구현하지 않는다. **현재 MVP는 PG 없는 직거래**다.

---

## 절대 금지

| # | 금지 | 올바른 방식 |
|---|------|-------------|
| 1 | `orders` / `payments` / `chatRooms` 메타를 클라이언트에서 create·update | Cloud Functions callable만 |
| 2 | 상품 `status`를 클라이언트가 `reserved`로 직접 변경 | `createDirectTrade` 등 Functions |
| 3 | 스토어/모바일 이메일·비밀번호 회원가입·비번 찾기 UI | 소셜만 (Google / Kakao / Naver) |
| 4 | Vercel·별도 Express/Nest/PostgreSQL 서버 신규 도입 | Firebase only |
| 5 | Firestore DB를 `(default)`/nam5로 가정 | named DB **`default`** |
| 6 | Functions region을 임의 변경 | **`asia-northeast3`** |
| 7 | 모노레포 `apps/` 아래에 store/admin/mobile 재생성 | 스토어=`car_factory_web/`, 어드민=`car_factory_admin/`, 앱=`car_factory_app/` |
| 7b | **`mechanic` / `mechanic_admin` 파일 수정·삭제·커밋 금지** | UI·패턴 **읽기 참고만**. 카팩토리 코드에만 반영 |
| 7c | 한글 깨진 파일을 인코딩만 바꿔 덮어쓰기 | **삭제 후 새로 생성** (유니코드 escape / node UTF-8) |
| 8 | `packages/`가 비어 있다고 타입을 한쪽에만 바꾸고 다른 앱 무시 | store / admin / mobile 계약 맞춤 |
| 9 | 예약중(`reserved`) 상품을 판매자가 단독 판매완료·자유 수정·삭제로 처리 | 거래 Functions + Rules 가드 |
| 10 | PG 체크아웃을 스토어에 재도입하며 직거래 플로우를 깨뜨림 | `COMMERCE_TODO` 순서 준수 |

## 쓰기 권한 한눈에

| 데이터 | 클라이언트 | Functions / Admin |
|--------|------------|-------------------|
| `users/{uid}` (본인, role/status 제외 필드) | R/W | — |
| `products` draft 생성·selling 수정(예약 잠금 준수) | 가능 | listingNumber는 Functions |
| `orders` | **읽기만** | 직거래 callables |
| `chatRooms` 메타 | **읽기만** | getOrCreate / triggers |
| `chatRooms/.../messages` | active·chatOpenUntil 내 create | system 메시지 등 |
| `admins/{uid}` | **쓰기 금지** | seed / createAdmin / setRole |
| `partners/{partnerId}` | 공개 읽기 | 어드민 대시보드 CRUD |
| `productListingCounters` / `orderCounters` | 금지 | Functions only |

## 인증 구분

| 대상 | 방식 | 게이트 |
|------|------|--------|
| 스토어·모바일 회원 | Google + (Kakao/Naver custom token) | `users/{uid}` |
| 어드민 | Email/Password | `admins/{uid}` + `isApproved` |

스토어 유저의 `users.role`과 어드민 `admins`는 별개다. 운영 권한은 **`admins` 컬렉션**이 기준이다.

---

## 커머스 (현행)

```
selling → reserved (createDirectTrade) → sold (complete) | selling (cancel)
```

- 예약·취소·판매완료: **판매자 중심** (UI는 채팅).
- `paymentProvider`: MVP는 `"direct"`.
- `/checkout`는 장바구니로 리다이렉트 — PG 없음.

상세: [04-커머스-직거래.md](./04-커머스-직거래.md)
