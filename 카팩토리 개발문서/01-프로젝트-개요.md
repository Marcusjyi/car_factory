# 01. 프로젝트 개요

최종 갱신: 2026-08-04

## 서비스

**CARFACTORY(카팩토리)** — 중고·자동차 부품 **C2C 마켓플레이스**.

현재 제품 방향: **PG 없는 직거래**. PG·에스크로는 이후.

## 워크스페이스 폴더 (모노레포 아님)

| 경로 | 역할 |
|------|------|
| `car_factory/` | **스토어**(Next 루트) + Functions + Rules |
| `car_factory_admin/` | **어드민** (Next.js, :3001) |
| `car_factory_app/` | **Flutter** 모바일 앱 |
| `카팩토리 개발문서/` | AI·사람용 개발 참조 |
| `mechanic_admin/` | UI 참고만. **파일 수정 절대 금지** |

`car_factory/apps/` 모노레포 구조는 **사용하지 않는다** (삭제됨).
