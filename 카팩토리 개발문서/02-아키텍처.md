# 02. 아키텍처

최종 갱신: 2026-08-04

## 구성도

```text
[Store Next :3000] ──┐
[Admin Next :3001] ──┼── Firebase Auth
[Mobile Flutter]  ──┘         │
                              ▼
                    Firestore DB `default`
                    Cloud Storage
                              ▲
                    Cloud Functions (asia-northeast3)
                    - 직거래 / 채팅방 / 관리자 / 리스팅번호
```

## 모노레포 트리 (핵심)

```text
car_factory/
├─ apps/store/          # Next 16, React 19, Tailwind 4
├─ apps/admin/          # Next 15.5, React 19
├─ apps/mobile/         # Flutter + Riverpod + go_router
├─ functions/           # Node 24, firebase-functions v7
├─ docs/                # COMMERCE_TODO, ADMIN_SCHEMA, 초기 스펙
├─ firestore.rules
├─ firestore.indexes.json
├─ storage.rules
├─ firebase.json
└─ package.json
```

## npm 스크립트 (앱별)

모노레포 루트 스크립트 없음. 각 폴더에서 실행한다.

| 위치 | Script | 동작 |
|------|--------|------|
| `car_factory/` | `dev` / `build` / `emulators` | 스토어·에뮬 |
| `car_factory_admin/` | `dev` / `create-admin` | 어드민 서버·관리자 시드 |
| `car_factory/functions/` | `build` / `deploy` | Functions |

## 백엔드 경계

- **클라이언트 허용**: 프로필, 상품 draft/판매중 관리(Rules 범위), 찜·장바구니·주소, 채팅 메시지(조건 충족 시).
- **Functions 전용**: 주문 생성·취소·완료, 채팅방 메타, 관리자 CRUD, 리스팅/주문 번호 카운터.
- **결제 확정·권한 변경을 브라우저가 직접 하지 않는다.**

## 배포

```bash
firebase deploy --only firestore:rules,functions
# 스토어: App Hosting (루트 디렉터리 apps/store)
```

에뮬레이터 포트(참고): Auth 9099, Functions 5001, Firestore 8080, Storage 9199, UI 4000.

## 소셜 로그인 주의

Kakao/Naver HTTP 콜백 구현은 `functions/src/auth/social.ts`에 있을 수 있으나, **`index.ts` export·시크릿 배포 여부**를 확인한 뒤 의존한다. 미배포면 콜백만으로는 동작하지 않는다.
