## 컬렉션 요약

| 경로 | 클라이언트 | 용도 |
|------|------------|------|
| `users/{uid}` | 본인 R/W (role/status 변경 불가) | 회원 프로필 |
| `publicProfiles/{uid}` | 공개 읽기 / 본인 displayName | 판매자 공개명 |
| `products/{productId}` | 상태·판매자 규칙에 따른 R/W | 상품 |
| `users/{uid}/favorites/{productId}` | 본인 | 찜 |
| `users/{uid}/addresses/{addressId}` | 본인 | 배송지 |
| `users/{uid}/cartItems/{productId}` | 본인 | 장바구니 |
| `users/{uid}/counters/{id}` | 본인 읽기 / **쓰기 금지** | 예: chatUnread |
| `orders/{orderId}` | 당사자·어드민 읽기 / **쓰기 금지** | 직거래 주문 |
| `payments/{paymentId}` | 읽기만 / 쓰기 금지 | PG 자리(미사용) |
| `chatRooms/{roomId}` | 참여자 읽기 / **메타 쓰기 금지** | 채팅방 |
| `chatRooms/{roomId}/messages/{id}` | 조건 충족 시 create | 메시지 |
| `supportInquiries/{id}` | 본인 create·read / 어드민 update | CS |
| `adminAuditLogs/{id}` | 어드민 읽기 / 쓰기 금지 | 감사 |
| `admins/{uid}` | 본인·어드민 읽기 / **쓰기 금지** | 운영 계정 |
| `productListingCounters/{dateKey}` | 금지 | 리스팅 번호 |
| `orderCounters/{dateKey}` | 금지 | 주문 번호 |

문서 ID: 회원·어드민 = Auth UID. 채팅방 = `{productId}_{buyerUid}`.

## Product

**파일:** `apps/store/src/types/product.ts`

| 필드 그룹 | 값 |
|-----------|-----|
| status | `draft` \| `selling` \| `reserved` \| `sold` \| `hidden` \| `blocked` |
| condition | `new` \| `used` \| `refurbished` |
| grade | `A` \| `B` \| `C` |
| delivery | `parcel` \| `direct` |

중요 필드: `sellerUid`, `title`, `partName`, `partNumber`, 차량 정보, `price`, `images[]`, `thumbnailURL`, `listingNumber`(`CF-YYMMDD-NNNNN`), `searchKeywords`, `reservedBuyerUid`, `activeOrderId`, `soldAt`.

규칙 요약:

- 생성 시 클라이언트는 `status: draft`만, **`listingNumber` 설정 금지**.
- `reserved` 전환은 Functions만.
- 예약중이면 수정·삭제·단독 판매완료 제한.

## Admin

**문서:** `car_factory/docs/ADMIN_SCHEMA.md`  
컬렉션: **`admins/{uid}`** (단수 `admin` 아님)

| 필드 | 타입 |
|------|------|
| email | string |
| displayName | string |
| employeeId | string? |
| isApproved | boolean (`true`여야 로그인) |
| role | `admin` \| `super_admin` |
| createdAt / updatedAt | timestamp |

비밀번호는 Firestore에 두지 않음. Auth Email/Password만.

## Storage 경로

| 경로 | 규칙 |
|------|------|
| `product-images/{uid}/{productId}/{file}` | 공개 읽기, 소유자 쓰기 ≤10MB jpeg/png/webp |
| `profile-images/{uid}/{file}` | 동일 |
| `support-files/{uid}/{inquiryId}/{file}` | 소유자 |
| `chat-images/...` | **전체 deny** (미구현) |

스토어 업로드 관례: `{imageId}_{thumb\|list\|detail}.webp` (약 400 / 800 / 1600).  
구현: `apps/store/src/features/products/image-upload.ts`.
