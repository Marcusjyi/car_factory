# 05. 앱별 구조

최종 갱신: 2026-08-04

모노레포 `apps/` 없음. 폴더는 분리되어 있다.

## Store (`car_factory/`)

- Next.js 16 App Router, React 19, Tailwind 4, Zod, Firebase client/admin.
- Auth: Google + Kakao/Naver(커스텀 토큰). 쿠키 `cf_auth=1`로 미들웨어 보호.
- Firestore: DB id `default` (`src/lib/firebase/client.ts`).
- Firebase env 없으면 `lib/mock-data.ts` 폴백 — **프로덕션 로직을 mock에 두지 말 것**.
- 포트 **3000**. `npm run dev`

### 주요 라우트

| 경로 | 설명 |
|------|------|
| `/`, `/parts`, `/parts/[id]` | 홈·검색·상세 |
| `/login`, `/social-callback` | 인증 |
| `/sell`, `/sell/photos`, `/sell/complete` | 판매 등록 |
| `/cart`, `/checkout`→cart | 장바구니 |
| `/orders/[orderId]` | 거래 상세 |
| `/chat`, `/chat/[roomId]` | 채팅 |
| `/favorites`, `/mypage/*` | 찜·마이페이지 |
| `/support/*` | CS |

```text
src/features/{auth,products,cart,favorites,addresses,chat,trades}/
src/lib/firebase/

src/app/

```

## Admin (`car_factory_admin/`)

- Next 15.5, 포트 **3001**.
- Email/Password + `admins/{uid}` (`isApproved`, role).
- 라우트: `/login`, `/dashboard`, `/dashboard/users|products|orders|admins`.
- 시드: `car_factory`에서 `npm run create-admin -- ...`

---

## Mobile (`car_factory_app/`)

- Flutter, Riverpod, go_router. pub name `car_factory_app`.
- Android `com.carfactory.car_factory_app` / iOS `com.carfactory.carFactoryApp`.
- 웹과 동일 Firestore·Functions (`docs/MOBILE_DEV.md`).
- Google 로그인 구현. Kakao/Naver는 stub 가능.
- 주문 write: Functions만.

---

## Functions (`car_factory/functions/`)

- Node 24, region `asia-northeast3`, entry `src/index.ts`.
- 새 함수는 **index에서 export**해야 배포된다.
