## Store (`car_factory_web/`)

- Next.js 16 App Router, React 19, Tailwind 4, Zod, Firebase client/admin.
- Auth: Google + Kakao/Naver(커스텀 토큰). 쿠키 `cf_auth=1`로 미들웨어 보호.
- Firestore: DB id `default` (`src/lib/firebase/client.ts`).
- Firebase env 없으면 `lib/mock-data.ts` 폴백 — **프로덕션 로직을 mock에 두지 말 것**.
- 포트 **3000**. `npm run dev`

## Mobile (`car_factory_app/`)

- Flutter, Riverpod, go_router. pub name `car_factory_app`.
- Android `com.carfactory.car_factory_app` / iOS `com.carfactory.carFactoryApp`.
- 웹과 동일 Firestore·Functions (`car_factory_app/docs/MOBILE_DEV.md`).
- Google: Firebase `signInWithProvider`. Kakao/Naver는 stub.
- 주문 write: Functions만.
- Android 설정 파일: `android/app/google-services.json` (gitignore).
- iOS: `GoogleService-Info.plist` — 클라이언트 Apple ID 등록 후 추가 예정.

### Android 인증서 지문 (디버그 키스토어)

Firebase Console → 프로젝트 설정 → Android 앱 → SHA 인증서 지문에 등록.

| 종류 | 값 |
|------|-----|
| 패키지명 | `com.carfactory.car_factory_app` |
| SHA-1 | `F7:58:77:85:35:5B:E9:C5:4C:78:33:47:2C:97:DB:A9:93:75:CF:23` |
| SHA-256 | `78:92:27:99:EE:E6:48:4B:78:15:90:8E:F4:A5:D8:0C:05:A9:D0:DF:7F:A5:C6:61:66:07:13:DE:EA:9E:C1:C9` |

- 출처: 로컬 `~/.android/debug.keystore` (`androiddebugkey`) — **디버그/`flutter run`용**.
- 재발급: `keytool -list -v -alias androiddebugkey -keystore %USERPROFILE%\.android\debug.keystore -storepass android -keypass android`
- **문서에 넣어도 됨:** SHA 지문·패키지명.
- **문서/깃에 넣지 말 것:** keystore 파일, 비밀번호, `google-services.json` 본문.
- 스토어 배포 시 릴리스 키스토어 SHA를 **추가** 등록한다 (디버그 값을 대체하지 말고 병행).
