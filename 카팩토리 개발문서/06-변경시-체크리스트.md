# 06. 변경 시 체크리스트

최종 갱신: 2026-08-04

코드·Rules·Functions를 바꾼 뒤, 해당 항목만 골라 확인한다.

## 공통

- [ ] 작업 전 `카팩토리 개발문서` 관련 절을 읽었는가
- [ ] `mechanic` / `mechanic_admin`을 수정하지 않았는가
- [ ] Firestore DB id `default`, Functions `asia-northeast3`를 유지하는가
- [ ] 스키마/플로우 변경 시 **개발문서 + COMMERCE_TODO(필요 시)**를 갱신했는가

## 상품

- [ ] draft 생성 시 listingNumber를 클라이언트가 넣지 않는가
- [ ] reserved 전환이 Functions만인가
- [ ] reserved 상품의 수정·삭제·판매완료 가드가 깨지지 않았는가
- [ ] Storage 경로·WebP 다중 해상도 관례를 따르는가

## 주문·직거래

- [ ] orders 클라이언트 write를 추가하지 않았는가
- [ ] create/cancel/complete/setTradeTransferInfo 시그니처와 UI가 맞는가
- [ ] 예약 시 다른 채팅방 blocked/closed 정책이 유지되는가
- [ ] 판매완료 후 chatOpenUntil 정책을 깨지 않았는가
- [ ] PG UI를 넣었다면 COMMERCE_TODO 순서·직거래 병행을 검토했는가

## 채팅

- [ ] chatRooms 메타를 클라이언트에서 쓰지 않는가
- [ ] roomId `{productId}_{buyerUid}` 계약을 유지하는가
- [ ] chat-images Storage는 아직 deny — 이미지 채팅 활성화 시 rules+업로드 함께인가

## 인증

- [ ] 스토어/모바일에 이메일 가입을 넣지 않았는가
- [ ] 어드민은 `admins` + isApproved 게이트인가
- [ ] Kakao/Naver 의존 시 Functions export·시크릿·배포를 확인했는가

## 어드민

- [ ] 컬렉션 이름이 `admins`(복수)인가
- [ ] 권한 변경은 Functions(callable)인가

## 모바일

- [ ] 웹과 동일 컬렉션·callable 이름인가
- [ ] `MOBILE_DEV.md` 금지 항목을 위반하지 않았는가

## 배포 전

- [ ] `firestore.rules` / `storage.rules` / indexes 필요 변경 반영
- [ ] `functions` 빌드·export 확인
- [ ] 스토어·어드민·모바일 중 영향 앱 수동 스모크 (로그인, 예약, 채팅, 어드민 로그인)
